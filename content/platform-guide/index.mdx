This section is for people using the TEA platform day to day.
It covers the platform's main features: teams and sharing, publishing to Discover, templates, connecting a Google account, trash and retention, and live updates while others edit a case.
It also holds the reference pages: quick lookups for platform basics, element types, and terminology, plus the data retention policy and machine integrations.
Start with [Teams, sharing and permissions](/docs/platform-guide/teams-sharing-permissions) if you are setting up collaboration, or jump to the [reference](/docs/platform-guide/reference) section for quick lookups.
