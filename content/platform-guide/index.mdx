This section is the reference for using the TEA platform day to day.
Start with [Getting Started](/docs/platform-guide/getting-started) to create an account and find your way around the dashboard, then [Building a Case](/docs/platform-guide/building-a-case) for the editor itself.
From there, it covers the platform's other features: teams and sharing, publishing to Discover, templates, connecting a Google account, trash and retention, and live updates while others edit a case.
It also holds the reference pages: quick lookups for platform basics, element types and terminology, plus the data retention policy and machine integrations.
If you would rather learn by working through a guided example, the [TEA Trainee curriculum](/docs/curriculum/tea-trainee) is the interactive route through the same material.
