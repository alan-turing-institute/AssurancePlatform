In [Your First Sip of TEA](/docs/curriculum/tea-trainee/01-first-sip), you explored how a fairness goal branches into a strategy, testable claims and evidence. You also saw a monitoring branch with missing support. Now you build a small slice of that case yourself.

You will use the browser editor to create a working case, revise its top-level goal, describe its context, and add one strategy, property claim and evidence item. Use the Fair Recruitment AI example as practice material. The example's statements are teaching content, so do not present them as findings from a real hiring system.

The current **Create New Assurance Case** dialog starts with a blank case and a generated `G1` goal. It does not offer a starter-template choice. A JSON file can be imported separately, but this activity uses the blank case so that you practise building the argument.
