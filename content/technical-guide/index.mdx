Use this guide when you develop, deploy or extend the TEA Platform. The application uses Next.js App Router for its web interface and route handlers, PostgreSQL for storage, and Prisma for database access.

## Technology

| Technology | Role |
| --- | --- |
| Next.js 16 and React 19 | Web application and interface |
| TypeScript | Application language |
| PostgreSQL and Prisma 7 | Data storage and database access |
| React Flow | Assurance case diagram |
| Tailwind CSS 4 | Styling |
| NextAuth.js | Browser sign-in and sessions |
| Biome, Ultracite and TypeScript | Code checks |

The version numbers come from `package.json`.
